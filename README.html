Kubernetes en pratique

Un cours complet, du premier Pod à l'administration d'un cluster, à pratiquer sur un seul serveur Linux. Il est rédigé à partir de la documentation officielle de Kubernetes, en simplifiant les notions courantes et en détaillant les notions complexes.

Comment suivre le cours

Deux environnements tiennent sur le même serveur :

  • Environnement A : un cluster kubeadm à un nœud (containerd, Calico), proche d'une vraie installation.
  • Environnement B : un cluster kind à trois nœuds (un control plane, deux workers), pour les exercices à plusieurs machines.

Chaque leçon indique l'environnement à utiliser. Le cours cible Kubernetes 1.37 ; les points qui dépendent de la version sont signalés par « Selon la version ».

5. Stockage Volumes, PV et PVC, StorageClass, application avec données persistantes

7. Sécurité Contrôle d'accès, RBAC, ServiceAccounts, securityContext, Pod Security, durcissement

11. Étendre Kubernetes CRD, contrôleurs et opérateurs, politiques d'admission, autres extensions

13. Projet final Application à trois niveaux de bout en bout, avec solution commentée
14. Annexes Aide-mémoire kubectl, glossaire, versions d'API
